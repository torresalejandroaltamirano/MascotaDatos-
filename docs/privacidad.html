Política de privacidad de MascotaDatos

Actualizada el 16 de octubre de 2026. Aplicación Android «MascotaDatos».

MascotaDatos proporciona un directorio de servicios para mascotas y funciones opcionales para publicar avisos de animales perdidos, encontrados o en adopción, aportar datos de negocios y solicitar publicidad. Para ejercer derechos relacionados con tus datos, utiliza alttorres@hotmail.com, correo de soporte y privacidad autorizado para esta aplicación.

1. Datos que tratamos

Al registrarte, tratamos tu dirección de correo electrónico y la información necesaria para iniciar sesión. Las contraseñas se procesan mediante el servicio de autenticación Supabase Auth; no debes enviarlas a soporte. En los avisos puedes facilitar voluntariamente nombre o descripción de una mascota, sector y ciudad, fecha, fotografía y un método de contacto. Al solicitar la inclusión de un negocio o publicidad puedes facilitar nombre comercial, dirección, teléfono, sitio web, correo de contacto y el texto de tu solicitud.

Los favoritos y otras preferencias de uso pueden quedar almacenados localmente en el teléfono. La versión Android examinada no solicita permiso para obtener tu ubicación GPS; la selección de ciudad se realiza desde la interfaz.

2. Para qué utilizamos los datos

Utilizamos la información para crear cuentas, gestionar el inicio de sesión, mostrar avisos y fichas que decidas publicar, permitir su consulta, revisar reportes, administrar solicitudes comerciales, responder comunicaciones y proteger la seguridad del servicio. No es necesario crear una cuenta para consultar toda la información pública.

3. Qué información puede hacerse pública

Los datos que decidas publicar en un aviso o ficha pueden ser visibles para otras personas, incluidos nombres, fotografías, descripciones, teléfonos o correos que escribas en campos públicos. Por ello, evita publicar datos personales de terceros sin autorización o información sensible que no sea necesaria.

4. Proveedores y servicios externos

El servicio utiliza Supabase para autenticación, base de datos y almacenamiento de archivos. El proyecto de Supabase está configurado en una región de Brasil, lo que implica procesamiento fuera de Chile. El SDK web de Supabase se carga mediante el servicio CDN jsDelivr. Al abrir enlaces de mapas puedes dirigirte a Google Maps, sujeto a las políticas de ese proveedor. Los proveedores pueden procesar registros técnicos necesarios para prestar sus servicios.

En la versión examinada no se identificaron bibliotecas de anuncios Google AdMob, Firebase ni Google Analytics. Esta descripción deberá actualizarse si se añaden herramientas publicitarias o de medición.

5. Seguridad y conservación

Las comunicaciones con los servicios web utilizan HTTPS. Supabase aplica autenticación y reglas de acceso a la base de datos; el almacenamiento de fotografías del servicio está configurado como privado. Ninguna medida ofrece garantía absoluta frente a incidentes.

Las cuentas y publicaciones se conservan mientras sean necesarias para prestar las funciones solicitadas o hasta que corresponda eliminarlas. Las solicitudes de eliminación requieren verificación de titularidad. Algunos datos podrían mantenerse únicamente cuando exista una obligación legal válida, que se informará al solicitante; las copias de respaldo y registros técnicos pueden estar sujetos a los ciclos de conservación de los proveedores.

6. Acceso, corrección y eliminación de cuenta

Puedes solicitar acceso a tus datos, corrección o eliminación escribiendo a alttorres@hotmail.com. Si tienes una cuenta, encontrarás además una opción para registrar una solicitud autenticada desde «Mi cuenta».

También existe una página pública para solicitar eliminación de cuenta y datos. El registro de una solicitud no elimina los datos automáticamente. La atención requiere verificar la titularidad y ejecutar el procedimiento correspondiente sobre cuenta, publicaciones y archivos. No compartas contraseñas ni códigos de acceso al solicitar asistencia.

7. Cambios y contacto

Si cambian los datos tratados, los proveedores o las funcionalidades de MascotaDatos, actualizaremos esta política. Para consultas de privacidad o soporte, escribe a alttorres@hotmail.com.
